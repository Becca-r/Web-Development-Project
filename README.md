# INSTALL DEPENDENCIES

`pip install -r requirements.txt`

# HOW TO RUN

## WINDOWS

`python app.py`

## MAC/LINUX

`python3 app.py`

# OUR BACKEND TECH

**HTMX**: A javascript libray that dynamically updates parts of a webpage using html attributes. 
This library also allows you to make AJAX requests without needing to write complex javascript!

**Flask**: A lightweight web-framework that is easy to use and can be scaled up to be used in complex projects!

**JINJA**: An easy to use templating language that pairs well and is designed to work with Flask. 
Jinja supports for loops, if statements, and even value insertion.

**Json** (Javascript Object Notation): Data structured in a human-readable format.

**JAVASCRIPT**: A programming language designed for the web. 
Javascript lets you interact and mutate elements within the DOM itself.

# OUR FRONTEND TECH

**HTML** (Hypertext Markup Language): A markup language that is the standard for the web. 
This language lets you define the structure and content of a webpage.

**CSS** (Cascading Style Sheets): A style sheet language that is the standard for the web. 
This language defines the presentation of elements for the webpage.
